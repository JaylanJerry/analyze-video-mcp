## 已接受限制

- 上传缓存的首尾各 64 KiB 指纹不保证识别大小、文件身份及首尾均不变的中段改写；本轮已接受。需要更强保证时另行评估全文件哈希等代价。
- MP3 时长只认 Xing/Info/VBRI 帧数；没有可靠声明则未知，未知时长允许放行。不得恢复码率抽样估算。
- 通用路径脱敏不跨空白；实际输入路径由确定性层完整覆盖，公开 HTTP(S) 链接保留。完整界限见 [安全说明](../docs/SECURITY.md)。
- 模型自报计数、时间点和音频结论不作为已核验事实；不跨模型外推媒体能力。
- 音频-only MP4 的历史 HTTP 400 原因未定位，`MEDIA_MODEL_UNSUPPORTED` 的分类仍缺真实命中样本。费用金额尚未对账。
